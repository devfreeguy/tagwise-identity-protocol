## Client Options

### `TipClientOptions`

```typescript
type TipClientOptions = Readonly<{
  baseUrl?: string;   // Base URL of TIP API (default: "https://tip.tagwise.me")
  rpcUrl?: string;    // Solana RPC URL for direct chain reads & submitting txs
  fetch?: FetchLike;  // Custom fetch implementation
  rpc?: SolanaRpc;    // Pre-built @solana/kit RPC client instance
  programId?: string; // Custom program ID
}>;
```

## Response Models

### `ResolveResponse` & `IdentityResponse`

```typescript
type ResolveResponse = {
  tag: string;                 // e.g. "@alice"
  owner: string;               // Base58 Solana public key of owner
  wallet: string;              // Base58 Solana public key of payment destination
  verified: boolean;           // Verified identity flag
  merchant: boolean;           // Merchant status flag
  displayName: string | null;  // Human-readable display name
  avatar: string | null;       // Avatar image URL
  bio: string | null;          // User biography text
  preferredToken: string | null; // e.g. "SOL" or "USDC"
  paymentLink: string;         // Universal payment URL
};

type IdentityResponse = ResolveResponse;
```

---

### `AvailabilityResponse`

```typescript
type AvailabilityResponse = {

```

### `UnsignedTransactionResponse`

```typescript
type UnsignedTransactionResponse = {
  transaction: string;         // Base64 encoded unsigned Solana transaction
  pda: string;                 // Derived tag PDA address
  lastValidBlockHeight: number; // Expiration block height
};
```

### `QrResponse`

```typescript
type QrResponse = {
```
