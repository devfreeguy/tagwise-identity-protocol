Task-oriented walkthroughs for the four places people usually get stuck.

- [Registering a tag](/docs/guides/registering-a-tag): the server builds the transaction, the user signs and pays for it.
- [Wallet authentication](/docs/guides/wallet-authentication): challenge, sign, verify, no secret key ever touches the SDK.
- [Editing a profile](/docs/guides/editing-a-profile): which fields are an API call, which need a transaction, which you can't edit at all.
- [Resolving without the API](/docs/guides/resolving-without-the-api): why TIP still works if the service is down.
